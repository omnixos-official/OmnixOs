The Omnix journey

Built carefully.
Built for everyone.

Omnix OS 27 is a long-term project. This roadmap shows the planned path to a first public release.

2026

Vision and identity

Define Omnix OS, Orbit UI, the all-in-one software-pack approach, and the public website.

EARLY 2027

First development builds

Build an Ubuntu LTS and KDE Plasma foundation, then create early Omnix branding and welcome screens.

2027

Omnix Hub and software packs

Create the system for choosing Everyday, Study, Developer, Creator, Gaming, and Privacy packs.

LATE 2027

Public testing and Omnix OS 27

Test the ISO on real computers and virtual machines, fix issues, and prepare the first public release.

This plan will evolve as the project grows. The first goal remains simple: a polished, welcoming, dependable Ubuntu-based desktop.
